# Street Life

Exercice de mise en page éditoriale autour de la culture urbaine, repris comme démonstration HTML/CSS responsive.

## Objectifs
- Construire une structure de page claire avec HTML sémantique.
- Organiser une navigation et des blocs de contenu.
- Utiliser Flexbox et Grid pour la mise en page.
- Adapter l'affichage aux petits écrans.

## Technologies
HTML5 · CSS3 (Flexbox, Grid, media queries)

## Lancer
Ouvrir `index.html` dans un navigateur. Les images sont chargées depuis Unsplash et nécessitent une connexion Internet.

Projet pédagogique fictif, sans affiliation à une publication réelle.
