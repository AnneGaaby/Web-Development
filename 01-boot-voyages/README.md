# Boot Voyages

Mini-site de présentation d'une agence de voyages fictive, réalisé dans le cadre de ma formation en développement web.

## Pages
- Accueil : présentation et destinations.
- Tarifs : exemples de formules et prestations.
- Devis : formulaire de demande avec validation HTML.

## Technologies
HTML5 · Bootstrap 5 · CSS personnalisé · JavaScript Bootstrap

## Lancer
Ouvrir `index.html` dans un navigateur. Les ressources Bootstrap et les photographies sont chargées depuis des CDN externes ; une connexion Internet est nécessaire.

## Note
Projet pédagogique fictif. Les prix et offres sont des exemples sans valeur commerciale.
