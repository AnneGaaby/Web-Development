# Développement Web — Anne Gabrielly

Ce dépôt rassemble une sélection de travaux réalisés pendant ma formation en développement web, puis retravaillés pour présenter une version plus propre et accessible de chaque exercice.

## Projets

| Projet | Technologies | Description |
|---|---|---|
| [Boot Voyages](./01-boot-voyages/) | HTML5, Bootstrap 5, CSS | Mini-site de voyage avec accueil, tarifs et formulaire de demande |
| [Street Life](./02-street-life/) | HTML5, CSS3 | Page éditoriale autour de la culture urbaine, avec mise en page responsive |

## À propos des travaux

Les projets sont issus d'exercices de formation. Les versions publiées ici sont des versions de présentation retravaillées : structure clarifiée, adaptation mobile et documentation ajoutée. Elles ne représentent pas des sites commerciaux ni des services réellement disponibles.

## Lancer les projets

Chaque projet est un site statique. Ouvrir son fichier `index.html` dans un navigateur ou utiliser l'extension Live Server de Visual Studio Code.

## Compétences illustrées

- Structuration HTML sémantique
- Mise en page responsive avec CSS et Bootstrap
- Navigation entre plusieurs pages
- Formulaires HTML et validation native
- Accessibilité de base : libellés, textes alternatifs, contrastes et navigation clavier
